Credentials

Per platform, per client. One 1Password item per login: op://<vault>/<platform>.<client>. Values are never displayed.
A red row means every job for that platform + client pair returns AUTH errors until the credential is fixed in 1Password. Rotation needs no deploy; the next run picks it up.

Vaults & Service Accounts

Runner Policy

Global defaults. Actions and client overrides can tighten but never loosen risk gates.

Risk gates

Auto-approve login steps
Headless runs cannot ask a human to approve the login submit
Block destructive actions
Refuse clicks classified as delete / submit / save after login
Require match verification
Never extract from a record whose identity was not verified

Never run two sessions with the same platform + client login at once
